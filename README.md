# 🤖 Introdução à IA - Aula 01

## 👩‍💻 Sobre o projeto

Olá! Eu sou **Ellen** e este é o meu primeiro projeto da **Residência em Tecnologias de Inteligência Artificial Generativa (RAG)**.

O projeto realiza uma integração entre **Python e a API da OpenAI**, explorando os primeiros conceitos de IA Generativa e comunicação com modelos de linguagem (LLMs).

* Python
* OpenAI API
* Python Dotenv

## 📚 Aprendizados

Configuração de ambiente, uso seguro de chaves de API e primeiros passos no desenvolvimento de aplicações com Inteligência Artificial.
